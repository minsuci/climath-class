## 결정이 어떻게 바뀌었나

처음 잡은 방향에서 두 번 크게 틀었다. 그 과정 자체가 이 교재의 성격을 만들었다.

### 1차 안 (폐기) — 중학 과정을 천천히

초안은 "수포자 성인이니 음수 덧셈부터 천천히"였다. 1회차에 3시간을 음수+계산순서에 썼다.

**폐기 이유.** 성인은 산수를 이미 한다. 매일 돈 계산하고 할인율을 따진다.
음수 덧셈을 45분 드릴하면 배우는 게 아니라 **무시당하는 느낌만 남는다.**

여기서 얻은 게 이 교재의 1번 원칙이다:

> **낮춰야 할 것은 계산 난이도가 아니라 진입 심리 장벽이다.**

성인이 진짜 막히는 지점은 "문자가 나오는 순간"이다.
2,300원짜리 3개는 바로 계산하면서, 그걸 `2300x`로 쓰라면 손이 멈춘다.

### 2차 안 (폐기) — 지수·로그·통계로 마무리

밀도를 올려 12회차를 통계로 끝내는 안. 성인 실용성이 가장 크다는 판단이었다.

**폐기 이유.** 목표가 "함수 위주, 미적분까지"로 정해짐.

### 최종안 — 함수를 척추로, 미분까지

- **도착점**: 다항함수 미분 (12회차 «미분의 활용»)
- **범위 밖**: 삼각함수·지수로그함수의 미분. 36시간에 다항함수 미분까지도 빡세다.
- **전제**: 과제는 선택이 아니라 필수

## 설계 원칙 다섯

### 1. 낮춰야 할 것은 계산 난이도가 아니라 진입 심리 장벽

→ 2회차(문자와 식)에 가장 많은 시간을 쓴다. 거기가 최대 심리 고비.
→ "중1 과정" 같은 표기는 쓰지 않는다. 단원명으로만.

### 2. 규칙을 외우게 하지 않고 유도한다

**성인은 납득이 안 되면 넘어가지 않는다. 대신 납득하면 잊지 않는다.**

이게 아이 가르치는 것과 가장 다른 지점이고, 교재 전체의 톤을 정했다.

| 흔한 방식 | 이 교재 |
|---|---|
| "마이너스 곱하기 마이너스는 플러스" | 분배법칙에서 **유도** |
| "a⁰ = 1로 약속했다" | `a³÷a³`을 두 방법으로 계산해 **강제** |
| "a⁻ⁿ = 1/aⁿ 외워" | `a²÷a⁵`을 두 방법으로 계산해 **강제** |

1회차에서 인정한 규칙은 **분배법칙 하나뿐.** 나머지는 전부 거기서 나온다.
"규칙을 늘리지 말고, 규칙 하나를 끝까지 민다"가 1회차 한 장 요약의 첫 줄이다.

### 3. 기하를 따로 빼지 않고 좌표평면에 녹인다

별도 단원으로 두면 함수 흐름이 끊긴다.
피타고라스·닮음·넓이공식을 **함수의 재료**로 쓴다.

- 흡수 지점 ① — 4회차 (두 점 사이 거리 = 피타고라스, 직선의 방정식)
- 흡수 지점 ② — 9회차 (부피 공식, 닮음비 → 최적화 문제의 재료)

### 4. 회차마다 "미리 걸어두기"를 하나씩 심는다

성인 학습자 이탈 방지에 가장 잘 듣는 장치.

- 1회차 **72의 법칙** → 11회차 로그에서 회수 ("왜 하필 72인지는 11회차에서")
- 1회차 **유리화** → 4회차 두 점 사이 거리에서 회수
- 1회차 **표지의 곡선** → 12회차 오프닝에서 회수 ← 가장 큰 것

> ⚠️ **1회차 표지 그림과 12회차 오프닝은 한 몸이다.**
> 둘 다 `f(x) = x³ − 6x² + 9x + 3`. 1회차는 점 P(4, 7)의 접선만 그려놓고
> "12회 뒤에 이 기울기를 직접 계산합니다"라고만 한다.
> 12회차 오프닝에서 `f′(4) = 9`를 계산하며 정체를 밝힌다.
> **함수를 바꾸려면 `figures.py` · `lesson01.js` · `lesson12.js`를 함께 고쳐야 한다.**

### 5. 문항 구성은 계산 : 식 세우기 : 설명하기 = 1 : 1 : 1

**'설명하기'(서술형)가 이 교재의 특징.**
성인은 서술을 부담스러워하지 않고, 오히려 자기가 이해했는지 확인하는 도구로 쓴다.

예: "a⁰ = 1인 이유를 지수법칙을 이용해 설명하시오", "−3²과 (−3)²이 다른 이유를 설명하시오"

## 12회차 커리큘럼

**척추는 6회 → 10회 → 11회.** "기울기"라는 단어를 6회차에 심어 10회차에 회수한다.

| 회차 | 주제 | 척추에서의 역할 | 상태 |
|---|---|---|---|
| 1 | 수와 식의 문법 — 음수·지수·근호 | 도구 정비, 유도하는 태도 심기 | ✅ |
| 2 | 문자와 식 — 상황을 식으로 | **최대 심리 고비** | |
| 3 | 인수분해와 이차방정식 | 나중에 `도함수=0`을 풀기 위해 | |
| 4 | 좌표평면 — 거리·중점·직선 | 기하 흡수 ① | |
| 5 | 함수라는 사고방식 | "무엇이 무엇을 결정하는가" | |
| 6 | 일차함수 — 기울기는 변화율이다 | **미분의 씨앗** | |
| 7 | 이차함수 (1) — 포물선의 해부 | 곡선과 첫 만남 | |
| 8 | 이차함수 (2) — 최댓값·최솟값 | 최적화의 원형 | |
| 9 | 다항함수와 도형 | 기하 흡수 ② + 최적화 재료 | |
| 10 | 극한 — 무한히 가까이 | **최대 고비** (평균변화율 → 순간변화율) | |
| 11 | 미분 — 도함수와 접선 | 계산할 수 있게 됨 | |
| 12 | 미분의 활용 — 그래프 개형·최적화 | 도착 | ✅ |

## 회차 표준 구성 (3시간)

| 시간 | 블록 |
|---|---|
| 0:00 – 0:20 | 오프닝 — 지도 보여주기 + 오늘의 질문 |
| 0:20 – 1:10 | 블록 1 (개념 유도) |
| 1:10 – 1:20 | 휴식 |
| 1:20 – 2:10 | 블록 2 (개념 + 실생활) |
| 2:10 – 2:20 | 휴식 |
| 2:20 – 2:50 | 블록 3 — 통합 연습 (A 계산 / B 식 세우기 / C 설명하기) |
| 2:50 – 3:00 | 한 장 요약 + 과제 |

**성인 집중력 기준으로 50분 블록 3개가 한계.** 휴식을 줄이지 말 것.

오프닝에 20분을 쓰는 이유: **성인은 지도를 먼저 봐야 움직인다.**
"오늘 뭘 배우는가"가 아니라 "이게 어디로 이어지는가"를 보여주는 자리.

## 만든 것

### 1회차 «수와 식의 문법» — 17쪽 (본책 12 + 정답·풀이 5)

- 오프닝: 접선 그림 + 12회 여정을 문장 세 개로 예고
- 오늘의 질문: **"(−3) × (−4) = 12인 이유를 설명할 수 있습니까?"**
- 블록 1: 분배법칙에서 부호 규칙 유도
- 블록 2: 지수법칙에서 `a⁰ = 1`, 음의 지수 유도 / 복리 + 72의 법칙
- 문항 40 + 과제 15

### 12회차 «미분의 활용» — 23쪽 (본책 18 + 정답·풀이 5)

- 오프닝: 1회차 그림 재등장 → `f′(4) = 9` → **"계산에 20초가 걸렸습니다"**
- 세 문장 회수 표 (6회 / 10회 / 11회 / 오늘)
- 블록 1: 증감표, 극값. 성인이 가장 많이 오해하는 두 지점
  - **극대 = 동네 1등, 최대 = 전국 1등** (f(1)=7이 극대인데 f(5)=23)
  - **f′(a)=0이라고 항상 극값은 아니다** (x³의 x=0 반례)
- 블록 2: 최적화 네 단계 — 상자 만들기 / 울타리 / **가격 vs 매출**
  - 2,000원 깎았는데 매출이 20만원 느는 문제
- 마무리: 12회 전체 지도 + 앞으로 갈 길 (적분 / 삼각·지수로그 미분 / 확통)
- 과제 D는 답이 없다 — **"당신 일에서 최대·최소로 만들고 싶은 것"의 목적함수만 세워 오기**

## 산출물과 만드는 법

```
textbook/
├── lib/doc.js        렌더링 헬퍼 + buildDoc  ← 모든 회차가 공유
├── lessonNN.js       회차별 내용만
├── assets/figures.py 그림 생성 (matplotlib)
├── verify/           회차별 정답 검산 스크립트
└── out/              .docx 산출물
```

```bash
cd textbook
npm install docx        # 최초 1회
node lesson01.js        # → out/*.docx
node lesson12.js
python3 verify/lesson01.py    # 정답 검산
python3 verify/lesson12.py
```

- `.docx`는 **한/글에서 그대로 열린다.** `.hwp` 조판이 필요하면 한/글에서 다른 이름으로 저장.
- 한/글 자동화는 윈도우 전용이라 리눅스(원격 세션)에서는 `.hwp` 직접 생성 불가.
- **새 회차는 `lessonNN.js` 하나만 만들면 된다. 헬퍼를 복사하지 말 것** —
  회차가 늘어나면 서식이 조용히 어긋난다.

## 겪은 함정 (기술)

| 증상 | 원인 / 해결 |
|---|---|
| `√{ab}`가 중괄호째로 찍힘 | 중괄호는 `^` 뒤에서만 위첨자로 해석. 루트 안은 `√(ab)`로 쓸 것 |
| 답안 밑줄 4줄이 1줄로 합쳐짐 | **인접 문단의 같은 테두리는 병합된다.** `ruled()`를 표로 그리는 이유 |
| 표 배경이 검게 나옴 | `ShadingType.SOLID` → `CLEAR` |
| 박스가 페이지 경계에서 쪼개짐 | `TableRow`에 `cantSplit: true` |
| 앞 페이지가 반쯤 비어버림 | 이미지가 안 들어가면 통째로 다음 장으로 밀림. `PageBreak`를 빼거나 크기 축소 |
| 리눅스에서 `.docx` 미리보기 불가 | LibreOffice에 Writer 모듈 없었음 → `libreoffice-writer` 설치. 한글은 `fonts-nanum` |

**모든 답은 코드로 검산할 것. 손으로 만든 답은 반드시 틀린다.**
1회차 56항목, 12회차 전 문항을 sympy로 검증했고 스크립트를 `verify/`에 남겼다.
